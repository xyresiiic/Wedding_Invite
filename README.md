## 🌸 About The Project

This project is a beautifully crafted digital wedding invitation website designed to create a luxurious and memorable experience for guests.

The website combines elegant typography, smooth animations, aesthetic layouts, and romantic visuals to give the feeling of a premium wedding invitation.

Perfect for:
- 💌 Digital Wedding Invitations
- 💍 Couple Showcase Websites
- 📸 Pre-Wedding Galleries
- 🎉 Wedding Event Landing Pages
